# 动作链

状态：已实现。

## 执行

快捷键绑定共享行为入口与首个选区的初始模式。`BehaviorGraph` 保存入口、有序节点列表和事件出口，
`BehaviorRunner` 等待动作及其子列表完成，再执行同级列表的下一项。调用行为复用同一张图，运行使用独立快照。

选区上方的按钮决定截图或录制出口，整个出口的动作列表随之选择。普通选区节点可配置是否显示按钮；
「仅选区」始终隐藏按钮，确认时保存区域，不隐式捕获。保存的选区持续复用到重新选区、主动清除或显示器失效。
直接捕获入口可使用已存区域；「使用已选区域」在区域不存在时失败，「使用当前范围」允许回退到光标屏。

录制节点等待停止，再执行停止后的子列表。同一启动快捷键再次触发可停止本次录制。
独立停止入口停止录制后，先等待启动行为的后续列表完成，再执行停止入口的事件出口与后续列表。
轻点、长按、长按松开可以分别绑定不同入口；同一按键的这组手势共用长按阈值。

编辑节点等待保存或关闭。确认输出与成功导出进入保存出口，并完成当前编辑步骤；未输出便关闭进入关闭出口。
行为图负责确认输出后的复制与显式保存，自动保存副本使用全局配置，消费烘焙后的结果；编辑器帧源关闭释放后，后续动作仍可读取独立结果。
录制保存等待编码和文件完整写入。静图、文本与录制按本次运行上下文传递，不额外物化原始 spool。

取消和失败先执行对应出口；节点可配置是否继续同级动作。未开启继续时结束当前行为。
失效引用、未知动作、未知事件、执行回路、超深路径与超预算运行不会继续执行。无效入口不阻止其他有效入口。

## 动作目录

| 动作 | 当前行为 |
|---|---|
| `select` | 选择区域，模式决定截图或录制出口 |
| `scope.stored` | 读取已存区域，没有时使用光标所在屏幕 |
| `grab.still` | 截取本链区域，没有时截光标屏；选区定格与干净窗口设置有效 |
| `grab.window` | 截取区域命中的窗口本体；窗口画面不可用时失败 |
| `save.png` | 将本链静图保存到保存目录 |
| `capture.frame` | 立即截取光标所在屏幕，忽略本链区域 |
| `record.toggle` | 录制中停止；空闲时对本链或已存区域起录 |
| `record.start` | 要求本链区域；起录并等待停止 |
| `record.stop` | 要求正在录制；停止并保留录制产物 |
| `scroll.capture` | 要求本链区域；等待滚动拼接完成并产出静图 |
| `capture.delayed` | 等待倒计时完成并截取当前区域 |
| `ocr.selection` | 识别本链静图或当前区域，结果写入本链文本 |
| `pin.selection` | 将本链静图或当前区域钉在屏幕上 |
| `edit.result` | 编辑本链最近的实际捕获产物 |
| `edit.last` | 打开本链静图或上次截图 |
| `edit.lastvideo` | 打开上次录制的内存序列并移交帧所有权 |
| `notify.toast` | 静图使用捕获浮窗，录制、取消与失败使用轻提示 |
| `copy.clipboard` | 复制本次 OCR 文本或捕获产物，录制使用 GIF 与捕获剪贴板格式 |
| `settings.open` | 打开设置 |
| `help.open` | 打开帮助 |
| `select.only` | 隐藏模式按钮，选择并保存区域，不隐式捕获 |
| `scope.saved` | 读取有效的已存区域，不存在时失败 |
| `scope.clear` | 清除已存区域与范围轮廓 |
| `save.result` | 等待本次静图或录制完整保存 |
| `behavior.call` | 执行共享行为入口，等待完成后继续 |

## 存储

`ChainRevision` 为 3，`GraphRevision` 为 1。入口保存有序节点标识，节点保存动作、事件列表与继续策略。
快捷键只保存入口标识、初始模式和输入参数；导入字段 `Actions`、`OnComplete`、`OnFail` 支持动作链配置。
规范化别名并合并完成列表后，导入过程把选区之后的捕获与后续动作放入模式出口，保留重复动作与多产物顺序。
标准截图与录制绑定共用选区行为，保留各自的键位和初始模式。删除入口不会恢复出厂配置，悬空绑定不进入引擎。

读取设置时先保留 `settings.json.bak.<ChainRevision>`，再通过同目录临时文件写回。重复读取保持节点与列表不变。
备份或写回失败保留输入文件，内存配置仍可使用。

## 设置页

「快捷键」页录入键位、选择手势、设置时间阈值、选择入口与初始模式。删除与启用按钮位于录键框左侧。
「行为」页维护多个入口，动作卡片沿用装饰层拖动、固定落点尺子、占位和弹性落入。
点击动作进入其事件出口，一次编辑一层；模式与生命周期出口使用页签，路径可返回上一级。
每个出口保留独立的有序列表，可新建、删除、改序，允许重复动作和调用共享行为。

## 验证

SelfTest 覆盖图序列化、导入幂等、共享引用、入口隔离、异步等待、取消与失败、调用返回、循环防护、
模式分支、仅选区、持续复用、长按松开、编辑器保存与关闭，以及动作卡片的编辑和改序。
策略测试入口为 `SelfTest.exe behavior-policy`；窗口测试入口为 `SelfTest.exe behaviors`。
动作链导入与宿主接口的检查入口为 `SelfTest.exe chains`。窗口交互检查见 [../UIAUDIT.md](../UIAUDIT.md)。
