# 动作链

状态：已实现。

## 执行

`GestureInvoker` 将完整绑定投递到 UI 线程。`CaptureController.BeginChain` 为每条链创建 `RunContext`，
保存区域、窗口、定格画面、静图、OCR 文本与录制序列。`ActionChain` 按序等待每一步完成。
录制产物使用 `CapturedSequence` 与 spool，不为传递上下文额外编码视频文件。

选区上方始终显示截图与录制开关。默认档位取自随后第一个捕获步骤，开关控制这一步的实际类型。
同档保留窗口截图、滚动截图、延时截图等具体操作；切换档位执行区域截图或区域录制。
每次选区对应其后到下一次选区之间的第一个捕获，其余步骤按配置执行。没有显式捕获时，选区确认后执行所选捕获。
「选区后先按开始」控制交互选区产生的录制，直接使用当前范围的录制不等待开始按钮。

例如 `select → grab.still → record.start`：选截图时先截图再录制；选录制时依次执行两次录制，每次等待停止。
快捷键页在对应步骤上显示「跟随开关」。通用收尾使用「编辑捕获结果」，根据本链最近的实际产物打开编辑器。
静图与视频专属动作消费本链对应产物；链产生了另一种类型时，专属动作失败并执行失败策略。
没有产出任何结果的独立「编辑上次截图」「编辑上次录制」动作仍可使用控制器保留的产物。

录制步骤等待停止后继续。录制中再次触发同一动作链或停止动作会停止当前录制，等待中的链继续执行。
选区或拼接取消结束本链。步骤失败执行失败链一次；`Stop` 结束，`SkipStep` 继续。
异步绑定在受理时完成引擎匹配，`NextBinding` 的运行期失败按结束本链处理。

静图在产出时更新本链与上次截图，应用自动保存与提示音。链中有静图消费步骤时不自动弹截图浮窗。
OCR 完成后才执行复制等步骤；复制本链文本优先于图片。

## 动作目录

| 动作 | 当前行为 |
|---|---|
| `select` | 选择区域，开关控制随后第一个捕获步骤 |
| `scope.stored` | 读取已存区域，没有时使用光标所在屏幕 |
| `grab.still` | 截取本链区域，没有时截光标屏；选区定格与干净窗口设置有效 |
| `grab.window` | 截取区域命中的窗口本体；窗口画面不可用时失败 |
| `save.png` | 将本链静图保存到保存目录 |
| `capture.frame` | 立即截取光标所在屏幕，忽略本链区域 |
| `record.toggle` | 录制中停止；空闲时对本链或已存区域起录 |
| `record.start` | 要求本链区域；起录并等待停止 |
| `record.stop` | 要求正在录制；停止并保留录制产物 |
| `scroll.capture` | 要求本链区域；等待滚动拼接完成并产出静图 |
| `capture.delayed` | 等待倒计时完成并截取当前区域 |
| `ocr.selection` | 识别本链静图或当前区域，结果写入本链文本 |
| `pin.selection` | 将本链静图或当前区域钉在屏幕上 |
| `edit.result` | 编辑本链最近的实际捕获产物 |
| `edit.last` | 打开本链静图或上次截图 |
| `edit.lastvideo` | 打开上次录制的内存序列并移交帧所有权 |
| `notify.toast` | 显示本链静图或上次截图的浮窗 |
| `copy.clipboard` | 依次优先复制本链 OCR 文本、本链静图、上次截图 |
| `settings.open` | 打开设置 |
| `help.open` | 打开帮助 |

## 存储

`ChainRevision` 当前为 3。`Actions` 包含完整顺序，`OnFail` 保存失败链。
导入支持 `OnComplete` 并将其按原顺序接到主链末尾；保存时省略该字段。
`scope.select` 解析为 `select`，`capture.stored` 解析为 `grab.still`。
没有区域输入的导入 `record.start` 步骤前插入 `scope.stored`。
读取设置时先保留 `settings.json.bak.<ChainRevision>`，再通过同目录临时文件写回；重复读取不重复追加步骤。
备份或写回失败保留输入文件，内存配置仍可使用。

## 设置页

每条快捷键编辑一条通用动作链与失败链。选区与多产物步骤均保留在同一条链中。所有动作均可添加，允许重复和多个产物。
步骤显示需要与产出值，缺少前置值时在行内提示。左右箭头与拖动均可改序，叉号删除，加号打开动作目录。
窗口是否确实命中与录制是否正在进行由运行时判定。

## 验证

SelfTest 覆盖迁移幂等、设置备份、动作目录、前置值、编辑器改序、失败策略、取消、录制等待与继续、
选区开关、开窗默认档位、只替换一个步骤、多产物链与连续录制。护栏要求全量用例通过、名称唯一，并检查本文动作目录与代码一致。
不创建窗口的策略测试入口为 `SelfTest.exe switch-policy`。窗口交互检查见 [../UIAUDIT.md](../UIAUDIT.md)。
