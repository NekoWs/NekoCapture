# 注释与文档

注释只写代码难以直接表达的当前契约：单位与坐标、前置条件、所有权、线程、生命周期、失败约定及必要的取舍理由。
文档只保留当前行为、验证方式和未完成事项。变更记录由 git 保存。

## 代码注释

- 禁止变更叙述、需求编号、测试编号、提交短码、被注释的代码与无主 TODO。
- 禁止词包括 `此前`、`之前`、`原来`、`曾经`、`退役`、`弃用`、`改为`、`修掉`、`教训`、`历史`。
- `旧`、`不再`、`回归`、`修复`、`坑`、`bug` 需要结合语境审查，优先直接描述行为。
- `public`、`internal` 类型与成员有 `<summary>`；方法参数有 `<param>`，返回值有 `<returns>`。
  属性可用 `<value>`，继承实现可用 `<inheritdoc/>`。位置式 record 的声明不是方法。
- XML 文档以中文为主；代码符号与 API 术语保持英文。私有成员仅在语义非显然时写注释。
- 一行注释不超过 110 字符；行尾只写单位、坐标、归属或不可删除的理由。
- `#region` 只使用一层，标题描述职责。禁止含糊分类名。
- `src/` 单文件不超过 700 行；按职责拆 partial，每个分部有简短职责说明。
- 不重复相邻代码、方法名和测试名称，不在代码里复述文档。

## 护栏

`scripts/lint-comments.ps1` 扫描注释、region、文档覆盖与文件长度，跳过字符串字面量。
`scripts/lint-current-docs.ps1` 扫描开发文档与 PowerShell 注释中的变更叙述。
`CS1591`、`CS1573` 作为编译错误；内部可见成员的文档覆盖由扫描器检查。
扫描器误判应修正识别规则，不为满足扫描器添加无意义的标签。
逐行豁免格式是 `// lint-comments:ignore <理由>`；豁免必须有明确原因。
