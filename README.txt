FrameCapture 使用说明
====================
运行 FrameCapture.exe，程序常驻托盘。右键打开菜单，双击托盘进入选区。

快捷键与动作链
  默认 Ctrl+Alt+A：选区 → 截图。
  默认 Ctrl+Alt+R：选区 → 开始/停止录制 → 打开编辑器。
  在「设置 → 快捷键」中录入键位、选择触发方式并编辑动作链，修改即时生效。
  每一步可添加、删除、用左右箭头或拖动改序；缺少前置值时显示提示。
  录制步骤等待停止后继续执行，截图、录制、OCR、复制、保存与编辑可按顺序组合。
  链含产物步骤时，选区窗隐藏截图与录制开关；没有产物步骤时可跟随该开关。
  「选区模式开关」关闭时，无产物链只记录区域。「选区后先按开始」控制选区录制是否等待开始按钮。
  输入「使用当前范围」可直接读取已存区域，没有时使用光标所在屏幕。
  截图本身不写剪贴板；默认浮窗提供标注与复制。链里添加复制等消费动作时不自动弹浮窗。

选区
  拖框或吸附窗口；Tab 上钻父容器。放大镜显示像素、坐标与颜色，C 复制颜色。
  定格模式使用打开选区时的画面。确认与取消键位在快捷键页配置。

编辑器
  选中 V、线 L、圆 O、箭头 A、手绘 P、荧光笔 H、文字 T、马赛克 M、裁剪 C、序号 N。
  Delete 删除标注；Ctrl+Z 撤销，Ctrl+Y 重做。工具和命令键位均可配置。
  Ctrl+滚轮缩放，中键平移，Home 适配，End 逐像素；空格播放暂停，方向键逐帧。
  时间轴两端把手或 [ / ] 选择导出范围，Backspace 清除。
  Ctrl+S 保存帧、Ctrl+C 复制、Ctrl+P 贴图、Ctrl+O 识别文字、Ctrl+E 导出录制、Ctrl+H 视觉暂留。
  Enter 提交，Esc 取消。GIF 可直接导出；MP4 和 WebM 需要本机 FFmpeg。

贴图与 OCR
  贴图可拖动、磁边、滚轮缩放、Ctrl+滚轮调透明度、R 旋转、方向键微调，Esc 或双击关闭。
  OCR 使用 Windows 离线引擎；按设置显示结果窗或复制文本。动作链中的复制优先使用 OCR 文本。

滚动与延时
  滚动截图先选区域，再手动或自动滚动；完成产出长图，Esc 取消，托盘可继续上次滚动。
  延时截图按设置倒计时后截当前范围；倒计时不抢焦点，可取消。

设置与文件
  支持中文与英文、系统/浅色/深色主题、强调色、快捷键、自启动与管理员运行。
  自动保存副本默认关闭。显式「保存 PNG」步骤独立于该开关，使用设置中的保存目录。
  录制帧临时存放在磁盘 spool，编辑器关闭后释放；录制时长由用户停止或磁盘空间护栏控制。
  动作链设置读取时保留版本备份，完成动作按顺序保存到链尾。
