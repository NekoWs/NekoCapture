FrameCapture 使用说明
====================
运行 FrameCapture.exe（首次运行 Windows 可能提示，允许即可）。
常驻托盘（Win11 在任务栏小箭头 ^ 里），右键图标可设置/退出。

快捷键（默认可改）：
  Ctrl+Shift+R  设置捕获范围（拖框或吸附窗口，选好后沿用；再按一次可把选取层顶到最前（自动压制其他置顶窗口））
  Ctrl+Shift+G  捕获：点按 = 单帧快改（QQ 式，只有画笔条）
                     长按 = 录制按下到放开之间的画面，松开进编辑器

编辑器：
  画面下方外侧 = 画笔条（点/线/椭圆/箭头/手绘/裁剪/撤销/颜色/粗细 + 设置/帮助），常驻不隐藏；裁剪只改视图不毁数据，Ctrl+Z 可逐级撤销
  画面下缘内侧 = 播放条（上一秒/上帧/播放暂停/下帧/下秒 + 时间轴 + 保存帧/复制帧/存GIF/视觉暂留 + 取消/确定），鼠标离开半秒自动隐藏
  时间轴：点/拖中间 = 跳转预览；拖两端小把手 = 圈定导出范围（范围外变暗）
  悬浮条与编辑器按住空白处均可拖动；悬浮条拖过后不再自动归位
  空格=播放/暂停，方向键=逐帧，Shift+方向键=逐秒，Ctrl+Z/U 撤销重做，Enter=确定（GIF进剪贴板），Esc=取消（绘制态下先退工具、再按才放弃，误触不丢捕获）
   缩放：Ctrl+滚轮 以光标为锚放大缩小；PageUp/PageDown 或 Ctrl+加/减 = 放大/缩小；Home 或 Ctrl+0 = 适配；End 或 Ctrl+1 = 逐像素 1:1；放大后浏览态左键拖或按住中键平移（HUD 显示当前倍率）

  所有按钮悬停有说明气泡；设置→外观可切换 跟随系统/浅色/深色 + 强调色，全窗口平滑过渡
  设置→录制：可关「录制时显示范围边框」（关掉后录制期间屏幕上没有任何边框提示）

录制时的边框说明：
  旧行为是 Windows 11 自带的系统捕获提示边框（黄色 #FFD11C）。它只按"被捕获对象"绘制，
  而 WGC 只能整显示器捕获，所以那条边框永远绕整屏、与所选范围无关 —— 已改为关掉系统边框，
  由 FrameCapture 自己按真实捕获范围画描边（只提示、不进产物，用 WDA_EXCLUDEFROMCAPTURE 排除）。

产物：确定后 GIF 写入剪贴板（含文件形式），不自动落盘；胶片条在 %TEMP%\FrameCapture\agent。
