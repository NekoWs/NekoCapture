FrameCapture 使用说明
====================
运行 FrameCapture.exe（首次运行 Windows 可能提示，允许即可）。
常驻托盘（Win11 在任务栏小箭头 ^ 里）：悬停看手势条数与当前范围，右键打开菜单，双击=设置捕获范围。

快捷键（出厂默认如下；想改键或加动作，打开「设置 → 快捷键」，每条 = 组合键 → 动作序列，可再配「完成后」做什么，保存即生效）：
  Ctrl+Alt+A  截图：按下进入选区（拖框/吸附窗口/Tab 上钻父容器；选取中再按一次把选取层顶到最前，游戏等霸屏窗口会盖住它），松手即截进剪贴板（浮窗显缩略图，点它或按 Enter 继续标注）
              选区时光标旁有高倍像素放大镜 + 坐标/尺寸读数 + 光标下像素颜色（按 C 复制颜色 HEX），便于像素级精确选区/取色（设置「选区放大镜」可关）
  Ctrl+Alt+R  录制：按下进入选区，松手开始录（范围角亮 REC 徽标+计时）；录制中再按一次停止，成片进编辑器

编辑器（弹出即有键盘焦点，全键可操作；Esc 关闭后焦点归还原窗口）：
  工具行：选中 V（点已画标注=选中，拖动=移动，Delete=删除，选中后点色板/线宽=就地改这条标注的颜色/粗细[文字/序号粗细即字号]，均可撤销）/ 线 L / 圆圈 O / 箭头 A / 手绘 P / 荧光笔 H（半透明高亮，盖在文字上遮不住字）/ 文字 T（点画布输入 Enter 上屏；点已有文字再编辑）/ 马赛克 M（拖框块状化，线宽挡位=块粒度）/ 裁剪 C / 序号 N（点击放递增编号圆标 1、2、3…，做步骤/教程标注，删除后编号自动回退不重号）（浏览 X）；色板 5 色 + 调色板取色 K（自绘 RGBA 调色板：色相/饱和/明度/透明度 + HEX/RGBA 直填，含最近用色）；
          线宽 细/中/粗 + W 弹层 1–24px；撤销 Ctrl+Z/U，重做 Ctrl+Y 或 Y
  播放行：首帧/上秒 Shift+←/上一帧 ←/播放暂停 空格/下一帧 →/下秒 Shift+→/末帧
          时间轴：点/拖中间=跳转；拖两端把手或 [ / ] =圈定导出范围（HUD 显示「导出 a–b」，Backspace 清除）
          右侧：保存帧 Ctrl+S / 复制帧 Ctrl+C / 钉到屏幕 Ctrl+P / 识别文字 Ctrl+O / 导出录制 Ctrl+E（按「录制格式」出 GIF/MP4/WebM）/ 视觉暂留合成 Ctrl+H / 取消 Esc / 确定 Enter
  缩放：Ctrl+滚轮以光标为锚；PageUp/PageDown 或 Ctrl+加/减 放大缩小；Home 或 Ctrl+0 适配；
        End 或 Ctrl+1 逐像素 1:1（>1:1 自动最近邻不糊）；双击画布在 1:1 与适配之间来回；放大后左键拖或中键平移；HUD 显示当前倍率
  播放倍速：＋/－（×0.25–×8），0 复位
  裁剪只改视图不毁数据，可撤销可重做；标注随裁剪保留框内部分；拖框时框外压暗+三分网格，松开即应用
  Enter = 确定：裁剪段+标注烘焙后 GIF 进剪贴板（文件+位图+自定义格式），编码中 Esc 可取消
  所有按钮悬停有说明气泡；帮助窗 = 工具行右侧 ? 按钮，随时可查
  图钉（工具行右侧）：编辑器总在最前，默认关；偏好自动记住
  记住工具（设置→编辑器，默认开）：下次打开编辑器自动选中上次的工具/颜色/粗细

贴图到屏幕（Ctrl+P 或工具行图片按钮）：把当前帧（含标注/裁剪）作为无边框置顶小图钉在原捕获位置，可多张并存。
  拖动移动（松手自动磁边：贴所在屏幕边缘停靠，也会对齐到同屏其他贴图的边/中线，Snipaste 式，可在设置「拖动贴图自动磁边」关闭）；方向键微调位置 1px、Shift+方向键 10px（跟屏幕上的既有界面对齐用，鼠标拖不出这个精度）；滚轮以中心缩放(10%~600%)；Ctrl+滚轮调不透明度(20%~100%)；R 键顺时针旋转 90°；Ctrl+S 另存为 PNG；双击或 Esc 关闭；右键菜单 复制/另存为/识别文字/旋转/不透明度/关闭/关闭全部贴图（识别文字=对贴图做 OCR，写剪贴板，开「识别后显示结果窗」则弹结果窗）。

识别文字（Ctrl+O 或工具行「A字」按钮）：用 Windows 内置 OCR（离线、不联网、支持中英文）识别当前帧里的印刷文字，纯文本写入剪贴板，
  预览底部提示「已识别 N 字 · 已复制」。未安装 OCR 语言包时提示到「设置 › 时间和语言 › 语音」添加。
  设置「识别文字后显示结果窗」（默认关）开启时，另弹出结果窗：可查看/编辑识别文本、部分选中复制、一键「复制全部」（含字数统计）。

录制格式（GIF / MP4 / WebM）：设置「录制格式」决定「导出录制」(Ctrl+E) 与「自动保存副本」的默认容器——MP4(libx264)/WebM(vp9) 支持高帧率、体积小，需本机装 FFmpeg（软件运行时自动探测 PATH 与常见安装目录，未装则视频项提示安装、GIF 始终可用）；GIF 免依赖到处能贴但封顶约 50fps 且体积大。注意：编辑器「确定」(Enter) 写剪贴板始终是 GIF（聊天工具可直接粘贴）。
  装 FFmpeg 任选其一：① 命令行 `winget install Gyan.FFmpeg`（Win11 自带 winget，装完重开软件即识别）；② 到 ffmpeg.org 下载解压后把其 bin 目录加入 PATH。装好无需重启设置，下次导出即生效。
  高刷录制：设置「录制帧率」滑杆 10–240，或开「跟随显示器刷新率录满」（如 160Hz 屏就按 160fps 录，忽略手动值）。实际帧率受内容变化率与系统捕获投递限制——静态画面不会凭空产帧；要真正录满高刷，需被录内容本身以刷新率变化（全屏游戏/视频等）。
  录制包含鼠标指针：设置「录制」组可关，默认录出的画面带鼠标光标；关掉后成片干净无光标，适合做教程/演示后期自加高亮，或不想让光标乱入。

滚动截图（长图）：托盘「滚动截图（长图）」→ 拖选区 → 只管滚动目标窗口，后台自动找重叠拼接长图（进度实时显示）；点「完成」出图，按 Esc 随时取消（QQ 式）。网页/聊天记录/代码一屏截不下时用。

延时截图：托盘「延时截图（N 秒）」→ 倒计时期间去打开右键菜单/悬停提示/下拉框，到点自动截当前范围（QQ 式延时）。秒数在设置「截图」组选（关/1/3/5/10）；倒计时浮窗不抢焦点、不入镜，点「取消」或按 Esc 可中止。

截图后行为（设置→截图「截图后」，四选一）：截图（含滚动/延时等单帧捕获）完成后做什么——弹提示（默认，缩略浮窗点一下或按 Enter 进编辑器）· 进编辑器（复制后直接开标注，QQ 式）· 只复制（不弹窗不开编辑器，最快，范围轮廓闪一下作反馈）· 贴图（复制后直接把这张图钉在原捕获位置，Snipaste 式，可多张并存、拖动/缩放/标注）。录制不受此项影响，始终进编辑器。

自动保存副本（设置→产物，默认关）：开启后确定/保存时除写剪贴板外，另存一份文件到指定文件夹（截图→PNG，录制→按「录制格式」GIF/MP4/WebM）。

外观：设置→外观 跟随系统/浅色/深色 + 强调色，全窗口平滑过渡；录制项可关「录制时显示范围边框」。

录制边框说明：Windows 11 自带捕获提示边框（黄色）只按「被捕获对象」绘制、永远绕整屏，
FrameCapture 关掉系统边框，由自己按真实范围描边（WDA_EXCLUDEFROMCAPTURE 排除，只提示、不进产物）。

产物：确定后 GIF 写入剪贴板（含文件形式，位于 %TEMP%\FrameCapture），不自动落盘；
      GIF 帧延迟按真实时间量化到厘秒并保总时长（60fps 不提速）；胶片条在 %TEMP%\FrameCapture\agent（可关）。
