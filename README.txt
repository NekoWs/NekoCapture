FrameCapture 使用说明
====================
运行 FrameCapture.exe，程序常驻托盘。右键打开菜单，双击托盘进入选区。
轻量组件维护托盘与快捷键，界面按需启动；窗口与后台任务结束后，空闲三秒收起界面进程。

快捷键与行为
  默认 Ctrl+Alt+A：以截图模式进入选区。
  默认 Ctrl+Alt+R：以录制模式进入同一选区行为，再按启动键停止录制。
  「设置 → 快捷键」配置按键、手势、时间阈值、行为入口和初始模式。
  「设置 → 行为」配置动作与事件出口。点击卡片进入下一层，页签选择出口，路径返回上一级。
  动作卡片可拖动排序，加号添加，叉号删除；多个行为可并存，共享行为可被其他行为调用。
  选区上方按钮决定走截图或录制分支，两边的后续动作分别配置。
  「仅选区」隐藏模式按钮，只保存区域；区域持续复用到重新选择或主动清除。
  轻点、长按、长按松开可分别绑定截图、开始录制、停止录制等入口。
  录制停止、编辑器保存或关闭后，执行对应出口的动作列表。
  「选区后先按开始」控制选区录制是否等待开始按钮。

选区
  拖框或吸附窗口；Tab 上钻父容器。放大镜显示像素、坐标与颜色，C 复制颜色。
  定格模式使用打开选区时的画面。确认与取消键位在快捷键页配置。

编辑器
  选中 V、线 L、圆 O、箭头 A、手绘 P、荧光笔 H、文字 T、马赛克 M、裁剪 C、序号 N。
  Delete 删除标注；Ctrl+Z 撤销，Ctrl+Y 重做。工具和命令键位均可配置。
  Ctrl+滚轮缩放，中键平移，Home 适配，End 逐像素；空格播放暂停，方向键逐帧。
  时间轴两端把手或 [ / ] 选择导出范围，Backspace 清除。
  Ctrl+S 保存帧、Ctrl+C 复制、Ctrl+P 贴图、Ctrl+O 识别文字、Ctrl+E 导出录制、Ctrl+H 视觉暂留。
  Enter 提交，Esc 取消。GIF 可直接导出；MP4 和 WebM 可通过独立视频组件安装器启用，也支持系统 FFmpeg。

贴图与 OCR
  贴图可拖动、磁边、滚轮缩放、Ctrl+滚轮调透明度、R 旋转、方向键微调，Esc 或双击关闭。
  OCR 使用 Windows 离线引擎；按设置显示结果窗或复制文本。动作链中的复制优先使用 OCR 文本。

滚动与延时
  滚动截图先选区域，再手动或自动滚动；完成产出长图，Esc 取消，托盘可继续上次滚动。
  延时截图按设置倒计时后截当前范围；倒计时不抢焦点，可取消。

设置与文件
  支持中文与英文、系统/浅色/深色主题、强调色、快捷键、自启动与管理员运行。
  行为图配置复制、提示与显式保存；自动保存副本由产物页控制，显式保存等待写盘完成。
  最近截图与录制保存在磁盘，界面再次启动时按需读取；替换或消费产物后清理缓存。
  录制时长由用户停止或磁盘空间护栏控制。
  配置导入与写回前保留版本备份，动作与事件列表按顺序保存。
