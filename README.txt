FrameCapture 使用说明
====================

启动
  运行 FrameCapture.exe，程序常驻托盘。右键打开菜单，双击托盘进入选区。
  官网：https://nekows.github.io/FrameCapture/

快捷键与行为
  默认 Ctrl+Alt+A 以截图模式进入选区，Ctrl+Alt+R 以录制模式进入选区。
  在「设置 → 快捷键」选择双快捷键、选区与捕获、单快捷键或自定义方案。
  选区上方按钮决定进入截图还是录制分支；仅选区模式只保存范围。
  在「设置 → 行为」配置复制、保存、编辑、提示及事件分支，拖动卡片调整顺序。
  录制准备、开始、停止，以及编辑器保存、关闭后的动作均可配置。

选区与编辑
  拖动选择区域，或吸附到窗口与控件。吸附停留在截图设置中调整。
  编辑器提供箭头、文字、手绘、荧光笔、马赛克、裁剪与撤销重做。
  Ctrl+滚轮缩放，中键平移；空格播放暂停，方向键逐帧查看录制。
  时间轴两端把手选择导出范围，工具与命令键位在快捷键页配置。

格式与工具
  截图和 GIF 无需额外视频组件。MP4、WebM 可在录制设置中下载安装组件。
  OCR 使用 Windows 内置引擎，在本机识别文字。
  贴图支持拖动、缩放、旋转和透明度调整。
  滚动截图支持手动或自动滚动，拼接后生成长图。

设置与更新
  支持中英文、系统或明暗主题、自启动与可选管理员运行。
  在「设置 → 系统」开关自动检查更新，在「设置 → 关于」手动检查。
  配置默认保存在 %APPDATA%\FrameCapture\settings.json。
  项目与问题反馈：https://github.com/NekoWs/FrameCapture
