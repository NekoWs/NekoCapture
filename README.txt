FrameCapture 使用说明
====================
运行 FrameCapture.exe（首次运行 Windows 可能提示，允许即可）。
常驻托盘（Win11 在任务栏小箭头 ^ 里）：悬停看当前热键/范围，右键打开菜单，双击=设置捕获范围。

快捷键（默认可改，设置窗内点击按键框重录；两键相同会有琥珀色提示）：
  Ctrl+Shift+R  设置捕获范围（拖框/吸附窗口/Tab 上钻父容器，选好后沿用；再按一次把选取层顶到最前）
  Ctrl+Shift+G  捕获：点按 = 截图进剪贴板（浮窗显缩略图，点它或按 Enter 继续标注）；
                长按 = 录制按下到放开（范围角亮 REC 徽标+计时），松开进编辑器

编辑器（弹出即有键盘焦点，全键可操作；Esc 关闭后焦点归还原窗口）：
  工具行：选中 V（点已画标注=选中，拖动=移动，Delete=删除，均可撤销）/ 线 L / 椭圆 O / 箭头 A / 手绘 P / 文字 T（点画布输入 Enter 上屏；点已有文字再编辑）/ 马赛克 M（拖框块状化，线宽挡位=块粒度）/ 裁剪 C（浏览 X）；色板 5 色 + 调色板取色 K（含最近用色）；
          线宽 细/中/粗 + W 弹层 1–24px；撤销 Ctrl+Z/U，重做 Ctrl+Y 或 Y
  播放行：首帧/上秒 Shift+←/上一帧 ←/播放暂停 空格/下一帧 →/下秒 Shift+→/末帧
          时间轴：点/拖中间=跳转；拖两端把手或 [ / ] =圈定导出范围（HUD 显示「导出 a–b」，Backspace 清除）
          右侧：保存帧 Ctrl+S / 复制帧 Ctrl+C / 存GIF Ctrl+E / 视觉暂留合成 Ctrl+H / 取消 Esc / 确定 Enter
  缩放：Ctrl+滚轮以光标为锚；PageUp/PageDown 或 Ctrl+加/减 放大缩小；Home 或 Ctrl+0 适配；
        End 或 Ctrl+1 逐像素 1:1（>1:1 自动最近邻不糊）；放大后左键拖或中键平移；HUD 显示当前倍率
  播放倍速：＋/－（×0.25–×8），0 复位
  裁剪只改视图不毁数据，可撤销可重做；标注随裁剪保留框内部分；拖框时框外压暗+三分网格，松开即应用
  Enter = 确定：裁剪段+标注烘焙后 GIF 进剪贴板（文件+位图+自定义格式），编码中 Esc 可取消
  所有按钮悬停有说明气泡；帮助窗 = 工具行右侧 ? 按钮，随时可查
  图钉（工具行右侧）：编辑器总在最前，默认关；偏好自动记住

外观：设置→外观 跟随系统/浅色/深色 + 强调色，全窗口平滑过渡；录制项可关「录制时显示范围边框」。

录制边框说明：Windows 11 自带捕获提示边框（黄色）只按"被捕获对象"绘制、永远绕整屏，
已改为关闭系统边框，由 FrameCapture 按真实范围描边（WDA_EXCLUDEFROMCAPTURE 排除，只提示、不进产物）。

产物：确定后 GIF 写入剪贴板（含文件形式，位于 %TEMP%\FrameCapture），不自动落盘；
      GIF 帧延迟按真实时间量化到厘秒并保总时长（60fps 不提速）；胶片条在 %TEMP%\FrameCapture\agent（可关）。
